Temporal Feature Pipeline

Milliseconds (ms)
Hold Time (H) Dwell Time
Hold Time = Release Time(i) − Press Time(i)

How long the key was held down. Indicates individual key stroke duration and finger pressure.

Down-Down Time (DD) Digraph Latency
Down-Down Time = Press Time(i) − Press Time(i − 1)

Time between two consecutive key presses. Measures transition rhythm between key pairs.

Up-Down Time (UD) Flight Time
Up-Down Time = Press Time(i) − Release Time(i − 1)

Gap between releasing previous key and pressing current key. Can be negative for roll-over typing.
